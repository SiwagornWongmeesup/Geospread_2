## 1. ปรัชญาการออกแบบ (Design Philosophy)

หลักการ UX ที่สำคัญแพลตฟอร์มด้านความปลอดภัยและการแจ้งเตือน:

| หลักการ (Principle) | คำอธิบาย |
|-----------|-------------|
| **ชัดเจนแม้อยู่ในภาวะกดดัน (Clarity under stress)** | ข้อมูลต้องอ่านและเข้าใจได้อย่างรวดเร็ว เนื่องจากผู้ใช้อาจอยู่ในสถานการณ์ฉุกเฉิน |
| **ยึดแผนที่เป็นหลัก (Location-first)** | แผนที่คือหน้าแรกของการเข้าใช้งานและสะท้อนบริบทปัจจุบันเสมอ |
| **ลดความยุ่งยาก (Low friction reporting)** | การส่งรายงานหรือขอความช่วยเหลือต้องใช้ขั้นตอนให้น้อยที่สุด |
| **เน้นความเกี่ยวข้อง (Relevant over exhaustive)** | แสดงเฉพาะสิ่งที่สำคัญต่อตำแหน่งที่ตั้งและความสนใจของผู้ใช้จริงๆ |
| **เข้าถึงง่าย (Accessible)** | ต้องใช้งานได้ดีในสภาวะที่ไม่เอื้ออำนวย (เช่น แสงแดดจ้า หรือการใช้งานมือเดียว) |

## 2. หน้าจอและฟังก์ชันหลัก (Core Screens)

### 2.1 แผนที่เรียลไทม์ (Live Map)

**จุดประสงค์:** หน้าจอหลักและเป็นหัวใจสำคัญของ GeoSpread

**องค์ประกอบหลัก:**
- แผนที่ Mapbox แบบเต็มหน้าจอเป็นเลเยอร์พื้นฐาน
- หมุดแผนที่ (Pins/Markers) สำหรับเหตุการณ์ที่เกิดขึ้นในพื้นที่ที่กำลังดูอยู่
- การแยกแยะประเภทของหมุดด้วยสี, ไอคอน, หรือขนาด ตามความรุนแรง
- ตัวระบุตำแหน่งปัจจุบันของผู้ใช้
- ปุ่มลัด (Quick-action) สำหรับสร้างรายงานหรือขอความช่วยเหลือ

### 2.2 ฟีดเหตุการณ์อิงตามพื้นที่ (Location-based Feed)

**จุดประสงค์:** รายการเหตุการณ์ที่เกี่ยวข้องกับผู้ใช้ โดยจัดอันดับความสำคัญ

**องค์ประกอบหลัก:**
- เรียงลำดับตามความสำคัญ (Priority), ความใกล้ (Distance) และความใหม่ (Recent Activity)
- มีตัวกรอง (Filter) ระยะทาง เช่น 0–2 กม., 2–5 กม., 5–10 กม., 10+ กม.
- เหตุการณ์ระดับ Critical (วิกฤต) ต้องมีโอกาสถูกดันขึ้นมาด้านบนเสมอแม้จะมีคนสนใจน้อย
- เมื่อแตะที่การ์ดเหตุการณ์ จะซูมแผนที่ไปที่จุดนั้นและเปิดหน้ารายละเอียด

### 2.3 สถานที่ที่บันทึกไว้ (Saved Locations / Follow Area)

**จุดประสงค์:** ติดตามข่าวสารในสถานที่เฉพาะที่ผู้ใช้สนใจ (เช่น บ้าน, ที่ทำงาน, บ้านครอบครัว)

**องค์ประกอบหลัก:**
- หน้าจัดการสถานที่ที่บันทึกไว้ 
- เลือกตั้งค่าการแจ้งเตือน (Notification) แยกตามสถานที่ได้

## 3. โครงสร้างห้องเหตุการณ์เฉพาะกิจ (Event Room Structure)

สำหรับเหตุการณ์ที่สำคัญหรือมีผู้ให้ความสนใจจำนวนมาก ระบบจะสร้าง **Event Room** ขึ้นมาเพื่อเป็นศูนย์กลาง

| ส่วนประกอบ (Section) | หน้าที่ |
|------------------|---------|
| **Overview (ภาพรวม)** | สรุปเหตุการณ์ ระดับความรุนแรง พื้นที่ จำนวนผู้ติดตาม และสถานะปัจจุบัน |
| **Timeline (ไทม์ไลน์)** | ลำดับการอัปเดตสถานการณ์ตามเวลา (มี AI ช่วยสรุปเนื้อหาให้สั้นกระชับ) |
| **Chat (แชท)** | พื้นที่สนทนาแบบเรียลไทม์สำหรับผู้ใช้ที่ติดตาม Event นั้นๆ |
| **Help (ความช่วยเหลือ)** | รายการคำขอความช่วยเหลือ และการเสนอตัวเข้าช่วยเหลือ (Offer Help) เฉพาะในเหตุการณ์นั้น |
| **Map (แผนที่)** | แสดงขอบเขตพื้นที่และตำแหน่งหมุดย่อยๆ ที่เกี่ยวข้องกับเหตุการณ์นี้ |
| **Follow (ติดตาม)** | ปุ่มกดติดตาม Event เพื่อรับ Notification ทุกครั้งที่มีอัปเดตสำคัญ |

## 4. การโต้ตอบกับแผนที่ (Map Interactions)

| การโต้ตอบ | พฤติกรรม |
|-------------|----------|
| **แพน / ซูม** | ท่าทางมาตรฐานของ Mapbox ทั้งบนจอสัมผัสและเมาส์ |
| **แตะที่หมุดเหตุการณ์** | เปิดหน้ารายละเอียด Incident หากเป็นเหตุการณ์ใหญ่จะเชื่อมไปสู่ Event Room |
| **ปุ่มตำแหน่งของฉัน** | จัดกึ่งกลางแผนที่กลับมาที่ตำแหน่ง GPS ปัจจุบันของผู้ใช้ |

## 5. แบบฟอร์มการรายงานและการขอความช่วยเหลือ (Report & Help Request Forms)

เพื่อให้การรายงานรวดเร็วที่สุด:

| กฎ | รายละเอียด |
|------|--------|
| **เติมพิกัดอัตโนมัติ (GPS auto-fill)** | ใช้ตำแหน่งปัจจุบันของผู้ใช้เป็นค่าเริ่มต้น แต่สามารถเลื่อนหมุดปรับแก้ได้ |
| **แยกคำขอความช่วยเหลือออกจากแชท** | Help Request ต้องมีฟอร์มเฉพาะ ระบุประเภท จำนวนคน และสถานะ (Open → Accepted → In Progress → Resolved) เพื่อไม่ให้ตกหล่นในช่องแชท |
| **Nearby Help (ฉันช่วยได้)** | มีระบบแสดงคำขอความช่วยเหลือใกล้ตัว ให้คนแถวนั้นกดรับอาสาได้ |

## 6. สถาปัตยกรรมข้อมูลและการนำทาง (Navigation & Information Architecture)

การนำทางหลัก (Top-level Navigation) แนะนำดังนี้ (เช่น เมนูด้านล่างบนมือถือ):

| แท็บ (Tab) | หน้าจอ |
|-----|--------|
| 🗺️ **แผนที่ (Map)** | แผนที่ Live Map (หน้าแรกที่เป็นค่าเริ่มต้น) |
| 📋 **ฟีด (Feed)** | ฟีดเหตุการณ์เรียงตามระยะทาง/ความสำคัญ |
| ➕ **แจ้งเหตุ / ขอความช่วยเหลือ (Report)** | ปุ่มดำเนินการลัด |
| 🔔 **การแจ้งเตือน (Notifications)** | ศูนย์รวมการแจ้งเตือน |
| 👤 **โปรไฟล์ (Profile)** | โปรไฟล์ผู้ใช้, จัดการพื้นที่ที่ติดตาม (Saved Locations) |
