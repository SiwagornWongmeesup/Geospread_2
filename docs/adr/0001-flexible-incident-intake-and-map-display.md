# รับรายงานแบบยืดหยุ่นและกำหนดการแสดงผลแผนที่จากประเภท

GeoSpread รับข้อความเหตุการณ์อิสระและไม่บังคับให้ Community User เลือกประเภทหรือระดับความรุนแรง เพื่อให้รายงานเหตุที่ระบบยังไม่รู้จักยังส่งได้ ระบบจะแนะนำประเภทแบบไม่บังคับ; ประเภทมาตรฐานกำหนด Map Display Mode และ Impact Radius ของตนเอง ส่วนประเภทที่ไม่รู้จักแสดงเป็น marker รอตรวจสอบโดยไม่มีรัศมี เหตุผลคือรัศมีต้องอิงกติกาของประเภท ไม่ใช่การประเมิน severity ที่ไม่สม่ำเสมอจากผู้ใช้ และ Credibility ต้องคงเป็นค่าที่แยกจาก Severity เสมอ
