# ไฟไหม้

> ออกทันที · ก้มต่ำ · โทร 199

## ก่อนเกิด

> รู้ทางหนี · มีถังดับเพลิง · เช็คปลั๊ก

### สัญญาณเตือน

- ได้กลิ่นไหม้ หรือเห็นควันจากปลั๊ก สายไฟ หรือเครื่องใช้ไฟฟ้า
- เสียงสัญญาณเตือนไฟไหม้ของอาคารดัง
- มีคนรายงานไฟไหม้ใกล้คุณในแอป

### เตรียมตัว

1. **รู้ทางหนีไฟอย่างน้อย 2 ทาง** ทั้งที่บ้านและที่ทำงาน
2. **อย่าวางของขวางทางหนีไฟ** และอย่าล็อกประตูหนีไฟ
3. **มีถังดับเพลิงไว้ในบ้าน** และรู้วิธีใช้
4. **ติดเครื่องตรวจจับควัน** และเช็คว่ายังใช้ได้
5. **อย่าเสียบปลั๊กพ่วงต่อกันหลายตัว** และถอดปลั๊กเมื่อไม่ใช้
6. **นัดจุดเจอกับครอบครัวนอกบ้าน** จะได้นับคนได้ว่าออกมาครบไหม

## ระหว่างเกิด

> ออกทันที · ก้มต่ำ · โทร 199

### ทำทันที

1. **ตะโกนบอกคนอื่นว่าไฟไหม้** แล้วกดสัญญาณเตือนไฟไหม้ถ้ามี
2. **ออกจากอาคารทันที** ไม่ต้องเก็บของ
3. **ก้มตัวต่ำแล้วคลานออก** ถ้ามีควัน อากาศใกล้พื้นยังพอหายใจได้
4. **ปิดปากและจมูกด้วยผ้า**
5. **โทร 199** เมื่อออกมาข้างนอกแล้ว บอกตำแหน่งและว่ามีคนติดอยู่ไหม

### ห้ามทำ

- ห้ามใช้ลิฟต์
- ห้ามกลับเข้าไปเอาของ
- ห้ามเปิดประตูที่ลูกบิดร้อน
- ห้ามดับไฟน้ำมันหรือไฟกระทะด้วยน้ำ
- ห้ามดับไฟเองถ้าไฟลุกใหญ่แล้ว ให้ออกมาก่อน

### ถ้าต้องผ่านประตู

1. **ใช้หลังมือแตะประตูและลูกบิด** ก่อนเปิด
2. **ถ้าร้อน อย่าเปิด** ให้ไปทางอื่น
3. **ปิดประตูตามหลัง** ช่วยชะลอไฟและควัน

### ถ้าติดอยู่ในห้อง

1. **ปิดประตูแล้วอุดช่องใต้ประตู** ด้วยผ้าเปียก
2. **โทร 199** บอกว่าอยู่ชั้นไหน ห้องไหน
3. **ส่งสัญญาณที่หน้าต่าง** โบกผ้าสีสดหรือเปิดไฟฉาย
4. **ห้ามกระโดดจากที่สูง**

### ถ้าไฟติดเสื้อผ้า

1. **หยุด** ห้ามวิ่ง
2. **ล้มลงกับพื้น** ใช้มือปิดหน้า
3. **กลิ้งไปมา** จนไฟดับ

## หลังเกิด

> ล้างแผลไฟไหม้ · ห้ามกลับเข้าไป · รอเจ้าหน้าที่

### ทำตามลำดับ

1. **ไปที่จุดนัดแล้วนับคน** ถ้ามีคนหาย ให้บอกเจ้าหน้าที่ อย่ากลับเข้าไปหาเอง
2. **รอเจ้าหน้าที่บอกว่าปลอดภัย** ก่อนกลับเข้าอาคาร
3. **ถ่ายรูปความเสียหาย** ใช้เป็นหลักฐานขอเงินช่วยเหลือและเคลมประกัน
4. **ไปหาหมอถ้าสูดควันไปมาก** แม้จะยังไม่มีอาการ

### ระวัง

- **ไฟที่ดูเหมือนดับแล้ว** อาจปะทุขึ้นมาใหม่ได้
- **โครงสร้างอาคาร** ที่โดนไฟไหม้อาจถล่มลงมา
- **ควันไฟ** ทำให้แสบตา ไอ หายใจลำบาก ถ้ามีอาการให้ไปหาหมอ

### ถ้าโดนไฟลวก

1. **เปิดน้ำสะอาดไหลผ่านแผล** นานประมาณ 20 นาที
2. **ถอดแหวน นาฬิกา** ก่อนที่จะบวม
3. **ปิดแผลด้วยผ้าสะอาด** ห้ามทายาสีฟัน น้ำปลา หรือยาหม่อง ห้ามเจาะตุ่มน้ำ
4. **โทร 1669** ถ้าแผลใหญ่ ลึก หรือโดนหน้า มือ อวัยวะเพศ
